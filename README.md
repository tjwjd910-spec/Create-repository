# 👑 던전 크루세이더 (Dungeon Crusader)

빛의 공주가 되어 자동 사냥터와 심연의 탑을 정복하는 모바일 세로형 HTML5 웹 RPG 프로토타입입니다.
앱을 열면 곧바로 게임이 아니라 **타이틀/로딩 화면 → 웅장한 오프닝 테마 → 4장 스토리 컷신 → 공주 닉네임** 순서로 시작합니다.
외부 CDN, 폰트, 이미지, 오디오 파일 없이 `index.html` 하나만 열면 바로 동작합니다.
(모든 그래픽은 Canvas 도트 렌더링, 모든 소리는 Web Audio API 실시간 합성)

## 실행

```
index.html 을 브라우저로 열기 (또는 폴더를 정적 호스팅)
```

- 기준 해상도 390×844, 모바일 세로형. PC에서는 가운데 폰 프레임으로 표시됩니다.
- 진행 상황은 `localStorage`(`dungeonCrusader.save.v1`)에 자동 저장됩니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 구조 (HUD · 4개 탭 · 던전 전투 · 모달/토스트 · 타이틀/컷신/닉네임 오버레이) |
| `style.css` | 다크 판타지 픽셀 UI 스타일 |
| `game.js` | 데이터(스테이지·몬스터·20층 던전·미션·아이템·강화·등급), 공주 픽셀 스프라이트, 세이브/구버전 마이그레이션, 스탯 |
| `render.js` | Canvas 배경(테마 8종) · 스프라이트 · 히트스톱/셰이크/순백 플래시/넉백/성광 빔 · 데미지 팝업 |
| `audio.js` | Web Audio API 칩튠 BGM(사냥터·던전) + 효과음 25종(서브베이스 펀치·성광 폭격·방어막 등) |
| `ui.js` | 사냥터 시뮬레이션(황금 고블린), 20층 턴제 던전 + 자동 전투 + 직업 스킬/궁극기/콤보/미션, 무한의 시련, 가방·성장·도감, 화면 갱신, 광고 훅 |
| `pets.js` | 펫 화면 — 동행 펫, 상자깡(소환) 연출, 조각 합성, 승급 |
| `jobpick.js` | 직업 선택/무료 전직 화면 (4직업 카드 · 스탯 성향 · 전용 스킬) |
| `intro.js` | 타이틀/로딩 화면(캔버스 왕국·심연의 탑·공주), 4장 스토리 컷신 연출, 닉네임 설정/변경, 공주 정보 시트 |

## 게임 루프

0. **오프닝 (타이틀 → 스토리 → 닉네임)**
   - **타이틀/로딩** : 심연의 균열이 갈라진 밤하늘 · 금빛 창문이 켜진 왕국 성 · 검을 든 공주 도트 · 우뚝 선 20층 마왕의 탑을 캔버스로 그리고,
     빛나는 금빛 로고(`던전 크루세이더 : 빛의 공주`)와 **0%→100% 로딩 바**(단계별 문구)를 표시합니다.
   - 로딩이 끝나면 `[✨ 모험 시작하기]`, 세이브가 있으면 `[▶ 이어하기]`(공주 이름·Lv·스테이지 요약) + `[🔄 처음부터]` 버튼이 나타납니다.
   - **첫 제스처에서 Web Audio 를 unlock** 하고 **웅장한 오프닝 테마**(D단조 78 BPM · 브라스 코드 스웰 + 팀파니 + 심벌 + 스트링 패드)와
     **시작 팡파레**가 동시에 울립니다. 로딩 중에는 게임 시뮬레이션·자동 저장이 멈춰 있어 세이브 시간이 흐르지 않습니다.
   - **스토리 컷신 4장** : ① 평화롭던 빛의 왕국에 심연의 균열과 탑 출현 → ② 기사단이 끌려가고 왕국의 빛이 꺼짐 → ③ 왕관과 성검을 든 공주의 결심 → ④ "이제 당신의 이야기가 시작됩니다".
     장면마다 캔버스 일러스트(노을·사슬·성당 아치·새벽 광선)와 타자기 텍스트, `[다음 ▶]` `[건너뛰기 ⏭]`, 진행 점이 있고 화면 탭으로도 넘어갑니다.
   - **닉네임** : 3장과 4장 사이에 `공주님의 이름을 정해주세요` 입력창이 뜹니다(1~10자, 비우면 `서쟈`, 추천 닉네임 6종, `[👑 이 이름으로 출발!]`).
     정한 이름은 4장 대사·HUD(`공주 ○○`)·오프라인 보상 문구에 즉시 반영되고 세이브(`playerName`)에 저장됩니다.
   - **다시 보기** : 상단 HUD 의 공주 이름/아바타를 탭하면 시트가 열려 `[✏️ 닉네임 변경]` `[📖 스토리 다시 보기]` `[🎬 오프닝부터 다시 보기]` 를 쓸 수 있습니다.

1. **주인공 — 빛의 공주** : 금발 장발 · 금빛 티아라 · 로열 블루/퍼플 드레스 · 빛나는 검을 든 픽셀 스프라이트.
   HUD 아바타, 사냥터, 던전 전투가 모두 같은 공주 스프라이트로 그려지고, 티아라 주변에 반짝임과 금빛 오라가 흐릅니다.
   호칭은 `공주 {닉네임}`(기본 `서쟈`), 레벨에 따라 칭호가 `티아라 견습생 → 어린 공주 → 견습 기사 → 로열 기사 → 왕실 수호기사 → 빛의 공주`로 바뀝니다.
1-1. **직업 (4종) — 성장 탭 · 프로필에서 무료 전직**
   - **성기사 공주** ⚔️ 성검·방패 / `신성 베기`(220% 신성 폭발) · `성역 수호`(회복 28% + 방어) / 궁극기 **성광 폭격** — 높은 체력·방어, 안정형
   - **원소 마도사 공주** 🔥 지팡이·마법진 / `파이어볼`(190% + 3턴 화상) · `빙결 파동`(160% + 1턴 빙결) / 궁극기 **메테오 스트라이크** — 폭발적 화력, 낮은 체력
   - **그림자 레인저 공주** 🗡️ 쌍단검·후드 / `연속 급소 찌르기`(2연타) · `그림자 분신`(4턴 추가 타격) / 궁극기 **천본앵 · 난무**(6연격) — 치명타·속도 특화
   - **광전사 공주** 🪓 대부·붉은 드레스 / `광폭 참격`(250%, 체력 6% 소모) · `피의 갈증`(4턴 공격 +40% · 흡혈) / 궁극기 **파멸의 일격**(잃은 체력 비례) — 최강의 한 방, 흡혈
   - 직업마다 **도트 스프라이트(무기·의상·팔레트)**, **기본 스탯 성향**(공격/체력/치명/속도 배율), **전용 스킬 2종 + 궁극기 연출·사운드**가 다릅니다.
   - 새 모험을 시작하면 **직업 선택 화면**이 뜨고, HUD 이름/아바타 → **직업 변경(무료 전직)** 또는 성장 탭 `전직` 버튼으로 언제든 바꿀 수 있습니다.
   - 구버전 세이브는 **성기사**로 이어서 시작합니다(기존 강타·화염베기 → 신성 베기·성역 수호).
2. **사냥터 (자동)** — 8개 스테이지, 스테이지당 몬스터 8마리 처치 시 다음 스테이지로 자동 진행.
   보상은 **골드·경험치·일반~고급 장비** 중심입니다. 이동·공격·데미지 팝업·골드 코인 연출이 자동으로 돌아갑니다.
3. **던전 (턴제 + ⚡ 자동 전투)** — **1~20층 · 5테마**, 층마다 **4~6웨이브 + 보스** (고층일수록 웨이브 증가).
   - **1~4층 고블린 소굴** → **5~8층 해골 지하묘지** → **9~12층 용암 화염 동굴** → **13~16층 얼음 수정 성채** → **17~20층 심연의 마왕성**.
     4층마다 배경·몬스터 색·보스가 통째로 바뀝니다(용암은 붉게, 얼음은 푸르게, 심연은 보랏빛).
   - **중간 엘리트 몬스터**(★ 정예, 체력 1.9배 · 2배 드랍)와 **미믹 보물상자**(장비 다량 드랍)가 섞여 나옵니다.
   - **보스 패턴**: `광폭화`(체력 50% 이하 공격력 +30%), `방어막 전개`(🛡 실드 흡수, 부수면 추가 타격), `연속 강타 3연격`.
     다음 행동이 상단에 예고되므로 방어/포션/궁극기 타이밍을 잡을 수 있습니다.
   [기본공격] [강타(210%, 쿨 3)] [화염베기(150% + 3턴 화상, 쿨 3)] [방어/반격(피해 70% 감소 + 반격)] [포션(45% 회복)] [✨ 성광 폭격].
   전투 화면 상단 `⚡ 자동 전투 ON/OFF` 를 켜면 턴마다 상황을 판단해
   **죽을 것 같으면 포션 → 방어, 체력이 낮으면 회복, 강타·화염베기 쿨이 돌면 스킬, 궁극기가 차면 보스·위기 상황에 자동 발동**하고
   웨이브부터 보스전까지 자동으로 진행합니다. 언제든 OFF로 직접 조작할 수 있습니다.
4. **✨ 성광 폭격 (공주 궁극기)** — 공격·피격·처치로 게이지가 차오르고 100%가 되면 필드/전투의 버튼이 금빛으로 빛납니다.
   발동하면 화면 전체에 빛의 기둥과 폭발이 쏟아지며 **공격력 9배 + 최대 체력 80% 피해**, 체력 25% 회복.
5. **콤보 시스템** — 연속으로 때릴수록 `15 COMBO!` 카운터가 올라가 공격력 최대 +30%, 골드 최대 +50%. 피격되면 초기화.
6. **상단 미션 바** — 사냥터·던전 상단에 `몬스터 15마리 처치 (8/15) · 보상 보석 5개` 한 줄 미션이 표시됩니다.
   완료되면 `보상 받기` 버튼이 금빛으로 바뀌고, 탭 한 번으로 수령하면 다음 미션이 자동으로 이어집니다(무한 반복).
7. **돌발 이벤트** — 사냥터에 가끔 **황금 고블린**(9초 제한, 골드 8배 + 보석)이, 던전에 **미믹 보상자**가 나타납니다.
8. **타격감(Juice)** — 치명타·스킬·궁극기 순간 **히트스톱(40~65ms)**, 강한 **화면 흔들림**, 맞은 몬스터의 **순백 플래시 + 넉백**,
   다중 검기 아크·치명타 별·불꽃 입자·성광 빔, 크게 튀는 데미지 팝업, 서브베이스가 강화된 타격음과 짧은 진동(지원 기기).
9. **던전 보상 = 장비 파밍 특화**
   - 웨이브 클리어 시 **장비 100% 드랍** (고급~영웅, 고층은 전설 확률↑), 미믹은 2개
   - 보스 처치 시 **장비 4개 보장** (전설 확률은 층이 높을수록 상승)
   - 획득 장비는 전투 중 상단 장비 띠와 전투 로그에 등급 색으로 표시되고,
     층 클리어 결과 모달에서 아이콘·등급·능력치 카드로 한눈에 보입니다.
10. **성장** — 골드로 공격력 / 최대 체력 / 치명타 확률 / 치명타 피해 / 사냥 속도 / 골드 획득 6종 강화, 착용 장비 강화.
11. **가방 — 장비 비교는 '기본 스탯' 기준** (강화 +N 제외)
   - 무기 · 방어구 · 장신구 3슬롯, 등급(일반/고급/희귀/영웅/전설), 장착/비교/분해/일괄 분해/정렬.
   - 비교는 **강화 수치(+N)를 뺀 순수 기본 스탯(원판 스탯 + 잠재옵션)** 으로 합니다. `compareItem` / `previewStats({baseOnly:true})` /
     가방 카드의 `▲ UP` · `▲+` · `▼-` · **[✨ 추천 장착]** · 가방 탭 알림 점이 모두 이 기준으로 동작합니다.
   - 그래서 **+6 강화된 장비보다 기본 스탯이 높은 미강화 장비**에도 `▲ UP` 이 정상적으로 붙습니다.
   - 카드에는 기본 스탯만 적고 강화는 `강화 +N` 배지로 분리하며, 상세 모달에서
     **`기본 스탯 (강화 +N 제외 · 비교 기준)`** 과 **`강화 +N 보너스 (비교에서 제외)`** 를 구분해 보여줍니다.
   - **잠재옵션(제련)** : 등급이 높을수록 잠재옵션이 최대 3개까지 붙습니다(공격력%·체력%·치명타%·치피%·**흡혈**·**보스 피해**·골드%).
     상세 모달의 **[제련]** 은 던전코인 + 골드로 옵션을 통째로 다시 뽑습니다. 잠재옵션은 기본 스탯 비교에 포함됩니다.
   - 전투에서 **흡혈**은 가한 피해의 일정 비율을 회복하고, **보스 피해**는 보스에게만 추가 피해를 줍니다.

12. **펫 — 상자깡(소환) · 동행 · 승급**
   - 하단 **[펫·상자]** 탭. 상자 3종: **나무 상자**(골드 1,500) → 일반~희귀, **황금 상자**(보석 30) → 고급~영웅, **전설 상자**(보석 110) → 희귀~전설.
     1회 / **10회(10% 할인)**, `[AD] 광고 보고 황금 상자 1회` 자리도 있습니다.
   - 연출: 상자가 흔들리며 빛이 모이고 → 터지며 광선·섬광 → 등급별 결과 카드(`NEW` / `승급 ★N` / `조각 +N`).
     등급에 따라 효과음이 달라집니다(일반 `chestOpen` · 영웅 `gachaRare` · 전설 `gachaLegend`).
   - 펫 12종(일반 3 · 고급 2 · 희귀 3 · 영웅 2 · 전설 2): 아기 슬라임, 박쥐 콩, 노랑 병아리, 숲 여우, 물의 정령, 별빛 여우,
     아기 드래곤, 눈토끼, 천사 부엉이, 황금 슬라임, 지옥 사냥개, 불사조.
   - **동행** : 장착한 펫이 사냥터·던전에서 공주 옆을 따라다니며, 펫마다 정해진 주기(1~3턴 / 2~3초)마다 **투사체 추가 공격**을 합니다.
   - **상시 버프** : 공격력% · 체력% · 치명타% · 치피% · 골드% · 드랍률% (펫·승급 단계에 비례).
   - **펫 보조 스킬** : 3번째 공격마다 발동 — 화염 숨결(화상) · 회복의 빛(체력 회복) · 방어력 감소(받는 피해 +18%) · 공격력 버프(+18%).
   - **승급** : 중복 획득 시 ★1~★5 승급(능력치 +20%/단계), ★5 중복은 **펫 조각**으로 전환. 조각으로는 등급을 골라 **확정 합성**(25/45/90/180/360)하거나
     보유 펫을 **승급**할 수 있습니다.
13. **도감 수집 보너스** (성장 탭)
   - **장비 도감 15칸**(슬롯 3 × 등급 5)과 **펫 도감 12칸** — 획득하면 자동 등록되고, 등록 수만큼 **영구 스탯 보너스**가 쌓입니다.
     장비 1칸 = 공격·체력 +0.5%, 펫 1칸 = 치명 +0.3% · 치피 +0.4%. 장비 도감 완성 시 공격·체력 +5%, 펫 도감 완성 시 치명 +3% · 치피 +10%.
14. **무한의 시련 (보스 러시)** — 던전 탭 맨 위 `♾️ 무한의 시련`.
   - 20층 너머 **끝없는 보스 행렬**에 도전합니다. 보스를 잡을 때마다 다음 보스가 HP ×1.24 · 공격 ×1.17로 강해지고,
     층 테마·보스가 4층 단위로 바뀝니다. 보스마다 골드·보석·던전코인, 5보스마다 **펫 조각 +25**.
   - 쓰러지면 기록이 저장되고(`최고 N보스`), 던전 탭 카드에 최고 기록이 표시됩니다.
15. **하단 탭 5개** — 사냥터 · 던전 · **펫·상자** · **성장(직업·도감)** · 가방. 390×844 세로 화면에서 탭이 비좁아지지 않게 5칸으로 정리했습니다.

  레벨업 팡파레, 던전 클리어 팡파레, 보스 등장, 버튼 클릭, 사운드 ON/OFF,

## 광고(수익화) 훅

`game.js` 의 `Ads.show(placement, onReward)` 가 광고 자리입니다. 프로토타입에서는 안내 토스트 후
바로 보상을 지급합니다. 실제 출시 시 이 함수 안에서 AdMob / H5 광고 SDK를 호출하고,
시청 완료 콜백에서 `onReward()` 를 부르면 됩니다.

| `reward_chest` | 가방 > 광고 자리 | 강화석 3개 |

## 세이브 / 마이그레이션

`localStorage` 키 하나(`dungeonCrusader.save.v1`)에 저장합니다. 세이브 버전은 `ver: 4`.
구버전(`ver1` / `ver2`, 5층 시절) 세이브를 읽으면 **잃지 않고 자동 변환**합니다 — 5층 클리어 기록은 그대로 유지되고
20층 배열로 확장되며, 없던 궁극기·미션·콤보 필드는 기본값으로 채워집니다.
**v3 → v4 마이그레이션** : 없던 `job`(성기사) · `pets` · `shards` · `codex` · `rushBest` 필드가 기본값으로 채워지고,
보유/착용 장비에서 **장비 도감이 자동 복원**되며, 잠재옵션이 없던 장비에는 빈 옵션 배열이 붙습니다(강화 단계·장비 전부 그대로 유지).
닉네임은 `playerName` 으로 저장되고, 이 필드가 없는 예전 세이브는 기존 `name`(기본 `서쟈`)을 그대로 이어받습니다 —
기존 유저는 타이틀에서 `[▶ 이어하기]` 로 바로 진입하며 컷신·닉네임을 다시 거치지 않습니다.
`[🔄 처음부터]` 는 확인을 한 번 받은 뒤 세이브를 지우고 처음 상태로 되돌립니다.

브라우저 콘솔에서 `window.Game` 으로 접근할 수 있습니다.

Game.state              // 현재 세이브 객체
