# ⚔️ 던전 크루세이더 (Dungeon Crusader)

자동 방치형 사냥터 + 직접 공략하는 수동 턴제 던전을 합친 모바일 세로형 HTML5 웹 RPG 프로토타입입니다.
외부 CDN, 폰트, 이미지, 라이브러리 없이 `index.html` 하나만 열면 바로 동작합니다. (모든 그래픽은 Canvas 도트 렌더링)

## 실행

```
index.html 을 브라우저로 열기 (또는 폴더를 정적 호스팅)
```

- 기준 해상도 390×844, 모바일 세로형. PC에서는 가운데 폰 프레임으로 표시됩니다.
- 진행 상황은 `localStorage`(`dungeonCrusader.save.v1`)에 자동 저장됩니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 구조 (HUD · 4개 탭 · 던전 전투 · 모달/토스트) |
| `style.css` | 다크 판타지 픽셀 UI 스타일 |
| `game.js` | 데이터(스테이지·몬스터·층·아이템·강화), 픽셀 스프라이트, 세이브, 스탯 계산 |
| `render.js` | Canvas 배경(테마 8종) · 스프라이트 · 이펙트 · 데미지 팝업 렌더러 |
| `ui.js` | 사냥터 시뮬레이션, 턴제 던전, 화면 갱신, 광고 훅, 오프라인 보상 |

## 게임 루프

1. **사냥터 (자동)** — 8개 스테이지, 스테이지당 몬스터 8마리 처치 시 다음 스테이지로 자동 진행.
   이동·공격·데미지 팝업·골드 코인 연출·장비 드랍이 자동으로 돌아갑니다. 스테이지 수동 선택/자동 진행 토글 지원.
2. **던전 (수동 턴제)** — 1~5층, 층마다 일반 3웨이브 + 보스.
   [기본공격] [강타(210%, 쿨 3)] [화염베기(150% + 3턴 화상, 쿨 3)] [방어/반격(피해 70% 감소 + 반격)] [포션(45% 회복)].
   적의 **다음 행동**이 상단에 표시되고, 보스는 체력 50% 이하에서 광폭화합니다. 웨이브 클리어 시 체력 18% 회복.
   보스 처치 시 희귀 장비 · 던전 코인 · 보석 · 강화석 지급.
3. **성장** — 골드로 공격력 / 최대 체력 / 치명타 확률 / 치명타 피해 / 사냥 속도 / 골드 획득 6종 강화, 착용 장비 강화.
4. **가방** — 무기 · 방어구 · 장신구 3슬롯, 등급(일반/고급/희귀/영웅), 장착/비교/분해/일괄 분해/정렬.

## 광고(수익화) 훅

`game.js` 의 `Ads.show(placement, onReward)` 가 광고 자리입니다. 프로토타입에서는 안내 토스트 후
바로 보상을 지급합니다. 실제 출시 시 이 함수 안에서 AdMob / H5 광고 SDK를 호출하고,
시청 완료 콜백에서 `onReward()` 를 부르면 됩니다.

| placement | 위치 | 보상 |
| --- | --- | --- |
| `reward_double` | 사냥터 하단 버튼 | 90초간 골드·경험치 2배 |
| `reward_chest` | 가방 > 광고 자리 | 강화석 3개 |
| `reward_gem` | 가방 > 광고 자리 | 보석 10개 |
| `dungeon_revive` | 던전 사망 모달 | 체력 60% 부활 |
| `offline_double` | 오프라인 보상 모달 | 오프라인 보상 2배 |

```js
// 예시
Ads.show("reward_chest", () => { /* 보상 지급 */ });
```

## 디버그 / QA 훅

브라우저 콘솔에서 `window.Game` 으로 접근할 수 있습니다.

```js
Game.state              // 현재 세이브 객체
Game.stats()            // 계산된 스탯
Game.refresh()          // 스탯 재계산 + 화면 갱신
Game.dungeon, Game.field
Game.scene, Game.battleScene
Game.simulateOffline(분) // 오프라인 보상 모달 테스트
```
